# 應用程式更新記錄

網站或 Android 應用程式使用者可察覺的變更。2026 年 11 月以前發行的網站變更，請見網站的 `/updates` 頁面（資料來自 `web/data/update_history.json`）。

## 未發行

### Android 應用程式

新增以網站 JSON API 打造的原生 Android 應用程式（Android 8.0 以上），提供英文與繁體中文介面。球友可瀏覽、篩選場次，從分享的連結開啟場次，以暱稱與 PIN 碼報名或退出，並透過 Firebase 雲端通訊追蹤場次通知。主辦人可新增、編輯、複製、封存與刪除場次，並進行點名與結算；管理員可管理場次、球友、使用者與聯絡訊息。應用程式沿用網站的配色，預設為黃色，並可在「應用程式設定」中連線到任何部署的伺服器。

### Android 應用程式場次表單易讀性

場次表單的欄位標籤改為維持單行，讓空白欄位與相鄰欄位高度一致；半寬的程度欄位只顯示程度數字，並在下方顯示程度名稱；退出期限的日期欄位比時間欄位更寬；區塊說明也不會再把標記擠到一旁。

### 場次資訊檔案選擇器

重新設計場次表單中匯入 `court_info.md` 的檔案選擇器外觀，使其與其他表單控制項一致。

### 場次留言板

每個場次現在在網站與 Android 應用程式中都有留言板。已報名的球友可使用報名時的暱稱與 PIN 碼提問與回覆；場次主辦人與管理員則以帳號身分發言，並可刪除留言及其回覆。頁面開啟期間留言板會自動更新，主辦人與留言者會收到新留言與回覆的通知。每則留言上限 500 字，同一 IP 在同一場次每 10 分鐘最多發表五則，已封存的場次不接受新留言。

### JSON API

新增位於 `/api/v1` 的版本化 JSON API，涵蓋場次、報名與退出、主辦人工具、帳號、聯絡與管理功能。API 以會過期的 Bearer 權杖登入，伺服器只儲存權杖的雜湊值，會員也可查看並登出已登入的裝置。網站與 API 共用相同的驗證、流量限制與權限規則。

### 留言板提示間距

移除繁體中文留言板提示兩句之間多餘的空格。
