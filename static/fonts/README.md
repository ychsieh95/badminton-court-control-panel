# Noto Sans Traditional Chinese

`NotoSansTC-VF.ttf` is the Traditional Chinese variable TrueType font from the official Noto CJK `Sans2.004` release. The server uses this bundled font to render social thumbnails, including regular (400) and bold (700) text.
